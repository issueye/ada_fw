关于 Ada Framework

一套以服务端渲染为默认、按需渐进增强的全栈前端方案， 由 Rust 提供渲染与数据能力，浏览器只承担交互。

{% call card.render("技术选型", "每一项都以「减少运行时复杂度」为前提") %}
Rust + Axum
高性能异步 HTTP 服务，统一的类型与错误处理。
Minijinja
运行时模板引擎，支持继承与宏，模板改动无需重新编译。
Tailwind CSS
语义令牌驱动，开发期走 CDN、生产期走本地构建产物。
Alpine.js
声明式交互，无需独立的前端构建与状态管理库。
{% endcall %} {% call card.render("设计理念", "SSR 优先 · 组件化 · 渐进增强") %}

页面由可复用组件模板组合而成。首屏完整渲染，保证可访问性与加载速度； 客户端交互按需增强，脚本加载失败也不影响内容的可读性。
